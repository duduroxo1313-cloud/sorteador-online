Perguntas de revisão

1. Qual é a diferença entre .value e .textContent?

A propriedade .value lê ou altera o valor de campos de entrada, como textarea e input. Já .textContent lê ou altera o texto de um elemento HTML.

2. Por que precisamos usar Math.floor() no sorteio?

Porque Math.floor() arredonda o número para baixo, gerando um índice inteiro válido para acessar um item do array.

3. O que aconteceria se não usássemos filter()?

Entradas vazias poderiam continuar no array e até ser sorteadas, dependendo de como os dados fossem tratados.

4. Para que serve event.preventDefault()?

Serve para impedir o comportamento padrão do formulário, evitando que a página seja recarregada durante o sorteio.

5. Qual é a diferença entre classList.add() e classList.remove()?

classList.add() adiciona uma classe CSS a um elemento. classList.remove() remove uma classe CSS desse elemento.

6. Por que usamos textContent em vez de innerHTML?

Porque textContent insere o conteúdo como texto simples, sendo mais adequado e seguro para exibir os nomes sorteados. O innerHTML interpreta o conteúdo como HTML.

7. Como você faria para permitir apenas números?

Poderia usar o input do tipo number com validação em JavaScript. Também seria possível verificar se o valor digitado contém apenas números.

8. Como armazenaria os itens no localStorage?

Usaria JSON.stringify() para transformar o array em texto e localStorage.setItem() para armazená-lo. Para recuperar os dados, usaria localStorage.getItem() e JSON.parse().

9. Qual desafio extra foi implementado?

Foi implementada uma animação CSS para destacar o resultado do sorteio quando o nome do vencedor aparece na tela.

10. Quais métodos do DOM foram utilizados?

Foram utilizados getElementById(), addEventListener(), classList.add(), classList.remove(), textContent e value, além de métodos para tratar os dados digitados.

11. Que problema encontrou e como resolveu?

Um problema possível é tentar realizar o sorteio sem digitar nomes. Isso foi resolvido com uma validação que exibe uma mensagem quando a lista está vazia.

12. O que você melhoraria em uma próxima versão?

Adicionaria um histórico de vencedores, uma contagem regressiva e a opção de impedir que um nome seja sorteado novamente.
